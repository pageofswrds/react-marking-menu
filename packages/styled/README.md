# @react-marking-menu/styled

Opinionated styled components for marking menus, built on `@react-marking-menu/core`.

## Status

🚧 **Work in Progress** - This package will be implemented after the core primitives are complete.

## Installation

```bash
npm install @react-marking-menu/styled
# or
pnpm add @react-marking-menu/styled
# or
yarn add @react-marking-menu/styled
```

## Features (Planned)

- SVG-based radial menu visualization
- Default theme with CSS variables
- Dark mode support
- Smooth animations
- Fully accessible out of the box
