# @react-marking-menu/examples

Example implementations showing different ways to use the marking menu library.

## Planned Examples

- **SVG Radial Menu** - Classic radial menu with SVG rendering
- **Canvas Implementation** - High-performance canvas-based menu
- **DOM-based Menu** - Simple CSS approach
- **Framer Motion** - Animated version with smooth transitions
- **Accessible Menu** - Screen reader friendly implementation
